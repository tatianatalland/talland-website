# talland.be

Statische website van Talland BV, gepubliceerd via GitHub Pages (map `docs/`).

- Teksten: `src/pages/*.html`
- Wettelijke gegevens (FSMA, KBO, adressen): bovenaan `src/build.py`, blok `BEDRIJF`
- Opmaak: `src/style.css`
- Bouwen: `python3 src/build.py` → schrijft alles naar `docs/`

Nooit wachtwoorden, klantgegevens of interne documenten in deze repository zetten: ze is openbaar.
